# 素材

宣传片像不像「真东西」，八成取决于真实素材的密度。AI 生成的画面只能当包装。

## 一、配额（硬指标）

| 项目 | 要求 |
|---|---|
| 每个功能段落 | ≥ 1 张真实界面截图或真实作品图 |
| 全片 | ≥ 8 张真实素材 |
| 作品展示 | 至少一段 ≥ 8 张真实作品的快切蒙太奇 |
| AI 生成图 | 只用于底纹、包装、转场；**不得**充当产品界面或作品 |

盘点时先把能拿到的东西列完，再开始写分镜。拿不到 8 张就先跟用户商量：要不要登录、要不要用户提供、要不要改成「只讲一个功能」的短片。

## 二、截图规格

| 项目 | 要求 | 检查方法 |
|---|---|---|
| 分辨率 | 源图宽度 ≥ 显示宽度 × 2（4K 成片里显示 1200px 宽，源图就要 ≥2400px） | `check_assets.py` 报宽度 |
| 比例 | 与场景容器一致，**不许拉伸** | 看截图里的圆形头像/logo 是否仍是正圆 |
| 内容 | 无活动横幅、无悬浮客服条、无个人隐私（右上角头像、用户名、手机号） | 逐张看 |
| 格式 | PNG（界面）/ JPEG 质量 ≥ 90（照片） | — |
| 命名 | `产品-页面-日期.png`，全小写英文 + 连字符，不用中文名 | — |

截图方式（按优先级）：

1. 浏览器打开页面 → 开发者工具设备模拟 1920×1080 → 截全页 → 裁切。
2. Playwright（装了的话）：`page.setViewportSize({width:1920,height:1080})` + `deviceScaleFactor: 2`。
3. 实在拿不到高清：把显示尺寸缩小（不要拉伸放大），并在分镜里标注「低清素材，只用于 0.7s 快切」。

## 三、版权边界

| 素材类型 | 默认处理 |
|---|---|
| 产品自有界面、自有作品 | 可用 |
| 第三方 logo、品牌名 | 只作指代（提到「在某某平台上」），不做主体、不做特效包装 |
| 平台截图里的他人作品 | 缩略、打码或只作背景，且不加评论性字幕 |
| 音乐 | CC0 / 已购买商用授权；免费音源要看清「是否可商用」 |
| 字体 | 用系统自带或 OFL 授权字体（思源黑体、Noto Sans SC）；商用字体不许默认套用 |
| AI 生成图 | 记录生成工具与提示词，确认该工具的商用条款 |

所有素材的来源、作者、授权状态写进 `调研笔记.md` 的素材表。用户选了「风险用户承担」时，把这句话原样写进 `需求确认.md`。

## 五、抓取工具

- 本仓库自带：`scripts-win/shot.ps1`（HTML → PNG，headless Chrome）。
- 页面快照、往期帖子图片：先用浏览器手动存，写清 URL 与时间。
- 平台 API / 网页抓取脚本**暂不提供**：平台绑定、易失效，等真有稳定需求再写，且遵守目标站条款。

## 六、素材不足时的降级顺序

1. 只讲一个功能，把 8 张配额压到 3 张，时长缩到 20 秒。
2. 用真实文案 + 大字排版讲卖点（不假装有界面）。
3. 用代码画的界面示意（**必须**标注「示意图」，不能让人以为是真界面）。
4. 最后才是 AI 生图当包装。
