# promo-video-skill 宣传片 · 需求确认

> 本文是阶段 2 的共识文件。用户回复「开始」后进入全自动制作，改动一律追加到末尾的「修改记录」。

## 产品

- 一句话定位（`README.md:3` 原话）：把「做一支产品宣传片」拆成 AI 能照着执行的规范，配一套可跑的 Remotion 骨架和会 fail 的校验闸门。
- 目标用户：想给自家项目加一支宣传片的独立开发者（会写代码、没有剪辑师、也不想为一条 60 秒的片子学 AE）。
- 核心卖点（按片中出现顺序）：
  1. **十一道闸门，一条命令，会 exit 1** —— 不是"建议"，是跑完就判死。
  2. **一份 `timing.json` 管画面／字幕／旁白／音效／拍点** —— 错位只可能来自"改了一份没改另一份"。
  3. **声音零版权、零外部账号** —— BPM 合成配乐 + edge-tts 逐句配音，不买曲库、不接第三方 API。
- 可证明的数据（带出处）：
  - 坏项目 `verify` → 2 通过 / 3 警告 / 2 失败 / exit 1；点名"疑似小图放大…重复行列 88%"、"两张截图完全一样（差 0.00）：f060.png → f140.png"（`README.md:200-218`）。
  - `examples/bad.html` 跑 `probe.cmd` → 2 ERROR / exit 1：img 渲染 404×404 而原图 400×100（差 75%）（`README.md:156`）。
  - 配乐合成实测 100.0 BPM、相位偏差 −20ms（`README.md:232-249`）；旁白 RMS −18 dBFS、人声比音乐高 9.3 dB（`README.md:310、320-322`）。
  - 已交付真片：47.5s / 1425 帧 @30fps / 6 场景 / 4 张真实截图 / 10 句旁白 33.9s（占 71%）/ verify 5 通过 3 警告 0 失败 1 跳过（`README.md:301-312`）。
- 网址：https://github.com/yehuoshun/promo-video-skill （2026-11-15 已由私有改为公开，匿名访问 HTTP 200 已实测）

## 风格要点（B 施工图）

- 配色：底 `#eef2f7`（浅蓝灰图纸）／墨线 `#143b6b`／批注红 `#c1272d`／强调绿 `#1f7a4d`（仅用于 PASS）。
- 字体：标注与数字用等宽（`Cascadia Mono` / `Consolas`），中文标题用微软雅黑 Bold；不要在成片里混入第三套字体。
- 质感：40px 细网格 + 200px 粗网格；图框四角圆点；红色批注带引线；图签（项目／图号／依据／验收）常驻右下。
- 动效语言：尺寸线从左往右"量"过去（`ramp` + `enter(role:"head")`），批注红笔按笔画方向拉出；转场用"图纸平移"而不是淡入淡出。
- 明确不要的：不要深色科技感底、不要霓虹辉光、不要 3D 旋转、不要默认 ease 的弹跳、不要生图。

## 发布包装（三平台）

| 平台 | 视频 | 封面 | 标题基调 | tag 数量 |
|---|---|---|---|---|
| B 站 | 16:9 1080p60 · 52.8s | 16:9 1920×1080（施工图 + 红章「会 fail」） | 技术区语气，说清"这是什么、能干什么" | 6~8 个（编程 / AI / 独立开发 / 视频制作 …） |
| 抖音 | 9:16 1080p60 · 52.8s | 9:16 1080×1920（首帧即封面） | 前 3 个字就是钩子，标题短、口语 | 3~5 个话题 |
| 小红书 | 9:16 1080p60 · 52.8s | 3:4 1080×1440（方图信息密度最高） | 第一人称 + 数字，正文分点 | 5~8 个话题 |

封面统一走 B 施工图版式（同一套配色、字体、红章），只换构图与文案，保证三个平台看起来是"同一个作者"。

## 未定项 / 风险

- **ffmpeg 未安装**（doctor WARN）：抽帧、混音、换音轨会用到。若成片需要重编码以外的处理，得先 `winget install Gyan.FFmpeg`；本片按"Remotion 直出 mp4"规划，暂不依赖它。
- **真实素材尺寸**：`docs/img/*.webp` 多为网页截图，`check_assets.py` 会判"疑似小图放大"。阶段 4 逐张核 `--min-width 1920`，不够的现跑现截（verify 表、probe 报错、样板间）而不是放大。
- **视频托管**：`.gitignore` 里 `*.mp4` 被忽略，成片进不了仓库。README 嵌入需要单独上传（GitHub Release 附件或 issue 附件拿 `user-attachments` 链接），交付时一并说明。
