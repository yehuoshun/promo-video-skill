# 调研笔记（阶段 1）

## 一句话定位

`promo-video-skill` 是一个把「做宣传片」写成流水线的开源技能包：给它一句需求，它自己出施工图版式、
自己合成配乐、自己渲染，**交付前自己拿十一道闸门挑错**，有 ERROR 就 `exit 1`。

## 三条卖点（每条都能在仓库里找到原话）

1. **说「不行」也是功能。** `scripts-win/verify.ps1` 一次跑完十一道闸门（目录结构 / 环境 / 时间轴 / 素材 /
   离线素材 / 配乐 / 同步 / 静帧 / 排版 / 成片 / 编码），任一 ERROR 即 `exit 1`。
   出处：仓库 `scripts-win/verify.ps1`，实跑输出见 `assets-src/exhibits/data/verify-open.txt`。
2. **时间只认一个文件。** 画面、字幕、音效、节拍全部读 `timing.json`；字幕改了没重新合成，`sha1` 对不上就报错
   （`scripts-win/check_sync.py`）。所以不存在「画面切了字幕没跟上」。
3. **声音不用买。** `scripts-win/gen_music.py` 按 BPM 合成配乐，拍点由 `timing.json` 的 `beats` 决定，
   `check_audio.py` 实测 100.0 BPM、相位偏差 −10 ms。素材费 0 元，零版权风险。

## 事实边界（不许写进片子的东西）

- **没有**用户数、star 数、下载量这些数字——发布时仓库刚公开，任何「多少人在用」都是编的。
- **没有**「AI 自动剪片」这类说法：它不剪辑、不接第三方模型接口，只是按要求排版 + 渲染 + 自检。
- 「75%」「9.3 dB」「−10 ms」都是本机实测值，随重跑会变；写死在片子里时以 `assets-src/exhibits/data/`
  与 `check_audio.py` 的输出为准，重跑后要一并更新。
- 本机**未安装 ffmpeg**（`doctor.cmd` 报 WARN），成片靠 Remotion 自带编码器直出 mp4；
  片子里不提「需要另装 ffmpeg」。
