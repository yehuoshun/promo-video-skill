# yuque-import-skill 宣传片 · 发布物料

交付物清单 + 各平台可直接复制的文案。封面与视频都在本目录，`cover/` 里的 HTML 是封面源文件，改字重拍一条命令：

```bash
scripts-win\shot.cmd cover\cover-16x9.html cover\cover-16x9.png -Width 1920 -Height 1080 -Scale 1
```

## 一、成片

| 文件 | 规格 | 用途 |
|---|---|---|
| `out/demo-1080p.mp4` | 1920×1080 / 47.5s / 13.9MB / AAC 192k | B 站、YouTube 上传 |
| `out/demo-4k.mp4` | 3840×2160 / 47.5s / 31.8MB | 需要 4K 的平台（B 站大会员画质） |
| `out/demo-vertical-final.mp4` | **1080×1920** / 47.6s / 7.6MB | 抖音、视频号、小红书视频 |

竖版不是把横版裁一刀：`src/Vertical.tsx` 是一个竖屏壳——正片缩到 0.5625 放上部（顶边 300），
下面另起一套 54px 大字幕、三个数字 chip、仓库地址；横版那套 46px 字幕在竖版里关掉
（`<Video showSubs={false} />`），否则会出现一大一小两行一样的字。重出竖版：

```bash
cd examples/yuque-promo
npm.cmd run render:vertical     # → out/demo-vertical.mp4
ffmpeg -i out/demo-vertical.mp4 -c:v copy -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 -c:a aac -b:a 192k out/demo-vertical-final.mp4
```

> 竖版的取舍要讲明白：终端和目录树在手机上是「看得出是什么」，不是「读得清每一行」。
> 想让竖版也能读细节，得按 9:16 重排 Shot 的 `cardW/cardH`，那是重做一个片子，不在这版里。

音画：10 句旁白（edge-tts 晓晓，33.9s，占 71%）+ 100 BPM 程序配乐，人声比音乐高 11.7 dB；响度归一 -16 LUFS / TP -1.5。

**抖音专属注意**

- 抖音文案里的链接**不可点**，仓库地址放评论区并置顶，正文写「地址在评论区」

- 47 秒对纯工具演示偏长：如果数据不好，剪一版 20~25 秒的（保留 hook + 终端 + CTA 三场，时长规则见 `references/` 的节奏表，20 秒属于规则下限之外，需要另建 timing.json）

## 六、简介

**B 站 / YouTube（长版）**

```
把一整个 GitHub 仓库搬进语雀，一直是件体力活：目录要一层层建，文档要一篇篇贴，
建完发现层级塌了——一千多个节点里，几十篇挂在根目录上，全靠手工修。

这个开源工具把它变成一条命令：

    python scripts/yuque_tree_import.py --root ./d2l-zh --book <知识库ID> --dry

--dry 先空转，把要建的目录和文档一条条列出来给你看；
--test 6 只搬 6 篇试水；确认没问题再跑全量，进度写进 progress.json，断了能接着跑。
跑完还有一步对账（yuque_toc_reconcile.py），把语雀 TOC 和本地目录逐条比对，
差一条就报出来，而不是等你自己去翻。

片子里出现的都是真东西：真仓库（d2l-zh）、真输出（1210 节点 / 83 目录 / 1127 文档）、
真语雀界面（第 1 章 → 本章导读，层级一条没少）。到目前为止搬过 738 个库。

需要：Python 3.9+，一个语雀 token（设置页生成）。

仓库：https://github.com/yehuoshun/yuque-import-skill
MIT 许可，随便改。
```
