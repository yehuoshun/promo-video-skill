# 调研笔记：yuque-ai-mcp

> 调研时点 2026-11-18。本地仓库 `E:\DevSoftWare\DeepSeekWorkSpace\code\yuque-ai-mcp`（main，HEAD `d0d2890`，工作区干净）；公网抓取时间同为 2026-11-18。每句话都能回到下面某一行。

## 一句话定位

语雀知识库的 MCP Server：**65 个工具 / 13 个域**，45 个走 API Token、20 个走浏览器会话 Cookie，stdio + HTTP SSE 双传输，当前 `4.0.0`（MIT）。

## 目标用户

- 已在用 Claude Desktop / Cursor / OpenClaw 等 MCP 客户端、想把语雀接进 AI 的开发者（`AGENT-INSTALL.md:96` 明写适合这三家）。
- 语雀重度用户：需要批量导出、跨库复制、版本 diff、批量改目录这类「网页一次只能点一个」的活（`README_CN.md:67-79` 域表）。
- 投放受众：B 站「开源分享」合集里的开发者 / 效率工具爱好者，对工具数、依赖数、真实 star 敏感。

## 三条卖点（按上片顺序，每条附证据）

1. **65 个细粒度工具，同类的官方仓库只有 19 个。**
   - `/health` 实测自报 `{"status":"ok","version":"4.0.0","tools":65,"domains":{...13 键}}`（实现见 `server/src/http.ts:44-54`）。
   - `server/src/common/register-tools.ts:25-39` 的 `ALL_TOOLS` 是唯一注册源；src 与 dist 各 65 个唯一 `yuque_*` 名。
   - 官方 `yuque/yuque-mcp-server` README 第 88 行 `## Tools (19)`（`https://raw.githubusercontent.com/yuque/yuque-mcp-server/main/README.md:88`）。65/19 ≈ 3.4 倍，片子里只说「19 → 65」。
2. **官方缺的域它补齐。** `register-tools.ts:42-56` 的 `DOMAIN_COUNTS` 13 键：user 3 / search 3 / group 3 / doc 15 / toc 3 / repo 8 / statistic 4 / note 4 / recycle 3 / upload 1 / board 3 / mine 7 / web_doc 8 = 65（与 `README_CN.md:65-80` 逐行一致）。
3. **工程很轻：运行时只 1 个依赖，双传输共用同一注册中心。** `server/package.json:41-43` 的 dependencies 只有 `@modelcontextprotocol/sdk`；`index.ts`（stdio）与 `http.ts`（HTTP SSE :3099）都从 `register-tools.ts` 注册。

## 不许上片的说法

1. 「62 个工具」——仓库 About 描述、awesome 条目、`AGENT-INSTALL.md` 都是旧值。
2. GitHub 描述里的「RSS / 爬虫 / KV」——65 个工具里没有（只有一个扩展名白名单字符串 `"rss"`）。
3. 「45 OpenAPI + 19 web-API」同屏——与 45+20=65 自相矛盾。
4. 「45 个只走 OpenAPI」——62/65 个工具都 import 了 `api-client`，45/20 是功能归属口径。
5. 「比官方多 3 倍」——3.42 倍，只说「19 → 65」。
6. 「Node 18 起」——`package.json` 无 `engines`，出处是停在 v2.14.1 的过期文档。
7. 「67 个 skills」——仅徽章自述，关联仓库 5 个月未更新。
