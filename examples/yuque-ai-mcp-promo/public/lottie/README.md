# public/lottie —— Lottie 素材

`demo-badge.json`：**自绘演示素材，无第三方版权，可自由替换。**

## 这份素材从哪来

不是从 AE 导出、也没有从 LottieFiles 下载——是手写的 Bodymovin JSON（六条波纹图层
结构相同，用一次性脚本展开关键帧后落盘），八个 shape layer 全部由本项目自己画
（圆形底 + 勾号 + 六条外扩波纹），没有嵌图、没有嵌字体、没有引用任何外部
资产，因此不涉及第三方授权。改坏了大不了重画，不用担心版权。

- 版本字段：`v: "5.7.4"`、`fr: 30`、`ip: 0`、`op: 90`、`w/h: 512`（90 帧 = 3 秒 @30fps）
- 结构：8 个 shape layer（`ty: 4`），动效都写在 `ks` 的关键帧数组里
  - `check`：勾号路径 + trim path，第 12~44 帧描边生长（之后保持 100%），`st` 用底色画出「挖空」效果
  - `disc`：强调色圆底，静态
  - `wave1`~`wave6`：从圆边缘向外扩的描边环，第 0/15/30/45/60/75 帧各起一条、
    各活 20 帧（缩放到 170%、透明度 70% → 0），相邻两条重叠 5 帧 → 第 0~90 帧任意一帧都有波纹在动
- 颜色取自 `src/lib/theme.ts`：强调色 `#8ef0c8`、底色 `#07090d`。
  Lottie 里存的是 0~1 的浮点数组（`[0.5569, 0.9412, 0.7843, 1]`），不是 hex——
  改主题色时这里要一起改，否则和画面其余部分不同调。

## 怎么用

```tsx
import demoBadge from "../../public/lottie/demo-badge.json";

<Lottie frame={lf} fps={fps} data={demoBadge} from={0.12} width={520} height={520} />;
```

`data` 要的是解析好的对象，不是路径，所以 `import` 进来（`tsconfig` 已开
`resolveJsonModule`）。组件内部把「场景帧」换算成「素材帧」再交给 lottie seek，
不会自己跑时间轴，所以能嵌进 `Sequence` 也能在 Lab 里并排比对（细节见
`src/effects/Lottie.tsx` 的注释）。

## 为什么动画必须铺满整段

`op` 和最后一个关键帧都要落在这段画面结束的位置（这里 `op: 90`，正好是样板间一段的长度）。
少铺几帧，段尾就是死画面。

2026-11-14 实测（QA 逐帧量第 7 段中心 520×520 区域）：上一版最后一个关键帧在第 66 帧，
第 67 帧起定格——末尾 1.5 秒（45 帧）的相邻帧差中位数只有 **0.0704**，运动段是 **2.0687**，
差 29 倍；墨量从 565 帧的峰值 35.96% 一路冻结在 23.266%。**这种「半段死画面」不会报 ERROR**：
`check_stills` 每个场景只比 35% / 85% 两帧，中间静止它看不出来。

所以现在改成六条波纹按 15 帧错开、每条活 20 帧（见上），保证任意一帧都有波纹在动。
换素材时先算一遍「`op` 是不是等于段长（这里 90 帧）、最后一个关键帧落在第几帧」，
差得多就把动画拉长或做回环。

## 改完怎么重新生成

结构、段长、主题色要改时**别手改 JSON**——六个波纹图层的关键帧是循环展开出来的，
手改必错。在 `template/` 下跑：

```
node tools/gen-badge.js
```

它会直接覆写本目录的 `demo-badge.json`。脚本里的 `OP = 90` 与样板间段长绑定，
段长改了要一起改 `OP` 与 `WAVE_STEP`/`WAVE_LIFE`（每条活 20 帧、每 15 帧起一条，
重叠 5 帧才能保证任意一帧都有波纹在动）。

## 换成自己的素材

1. 把 `.json` 放进这个目录（文件名小写、连字符）；
2. 在场景里 `import` 它，替换 `data`；
3. **用第三方 AE 模板/LottieFiles 素材时，商用授权要跟素材一起记**（写在
   素材清单或本 README 里：来源链接、授权类型、是否允许商用、购买凭据放哪）。
   方案第 4.1 节的要求：授权记录和素材同仓同目录，别只留在聊天记录里。
4. 检查素材本身别带自己的时钟（AE 里导出的表达式、`Math.random` 之类），
   否则同一帧渲两次结果会不一样。
