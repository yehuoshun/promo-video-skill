## 产品

- 一句话定位（`README_CN.md:24` 原话）：基于 Model Context Protocol 的语雀全功能 MCP Server —— 65 个工具，13 个域。
- 目标用户：每天在语雀写文档、又想让 Claude / Cursor / Cline 直接读写这些文档的开发者与团队。
- 核心卖点（按片中出现顺序）：
  1. **65 个工具、13 个域** —— 1 个 API 端点 = 1 个工具，细粒度（`README_CN.md:24`、`:161`）。
  2. **官方缺的那一半它补齐** —— 团队、回收站、上传、统计、版本、Diff、跨库复制（`README_CN.md:31`、`:162-163`）。
  3. **两条通道** —— 45 个走 OpenAPI（`X-Auth-Token`），20 个走浏览器会话 Web API（Cookie + `x-csrf-token`）（`README_CN.md:82`）。
  4. **stdio + HTTP SSE 双传输** —— 共享注册中心，改工具不用重启客户端（`README_CN.md:29`）。
- 可证明的数据（带出处，全部来自本地仓库原文）：
  - 65 个工具 / 13 个域（`README_CN.md:8`、`:24`、`:80`；逐域明细 `:65-80`）。
  - 官方 `yuque/yuque-mcp-server` 工具数 19（`README_CN.md:160`）；README 原话「比官方多 3 倍覆盖」（`:28`）—— 实际 65/19 = 3.42 倍，片子里只说「19 → 65」，不复述「多 3 倍」这句话。
  - 45 OpenAPI + 20 Web API 的拆法：`web_doc` 8 + `mine` 7 + `recycle` 3 + `upload` 1 + `web_search` 1 = 20（`README_CN.md:82`）。
  - 配置只有 4 个字段：`token` / `api_base` / `cookie` / `ctoken`（`README_CN.md:183-190`）。
  - HTTP SSE 端口 3099（`README_CN.md:58`、`:178`）；`config.json` 的 `toc_cache_ttl_minutes` 默认 60（`:192`）。
  - 语雀 API 对超过 5000 篇的知识库不可用（`README_CN.md:199`）。
  - 版本 4.0.0、MIT、TypeScript + MCP SDK 1.x（`README_CN.md:13`、`:239`、`:234-235`）。

## 风格要点

- 配色：（选定样帧后填）
- 字体：中文「微软雅黑」，数字/代码「Cascadia Mono / Consolas」。
- 动效语言：入场只走 `enter(frame, at, role)`；大容器用 `feel: "spring"`；转场 ≤0.6s；每 8~12 秒一个 ≥2s 定场镜头。
- 质感：网格、细描边、单色强调；**不用生图**、不用 3D 旋转、不用默认 ease 弹跳。
- 明确不要的：深色霓虹科技感堆砌、假界面冒充真截图。
