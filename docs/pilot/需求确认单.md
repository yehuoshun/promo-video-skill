## 一、这支片子要解决什么

| 项 | 内容 |
|---|---|
| 主角 | `code/yuque-import-skill`（MIT，个人项目） |
| 观众 | 有 GitHub/文档站收藏、想把内容搬进语雀但被「手动复制粘贴」劝退的开发者 |
| 唯一目标 | 看完知道**一条命令就能把整棵目录树搬进语雀，层级不变**，并愿意点进仓库 |
| 片长 | 45~60 秒（`check_timing.py` 的默认区间） |
| 平台 | 先在 README / X / B 站三处复用，横版 16:9，出 1080p 审片 + 4K 交付 |
| 不做 | 不讲架构、不列参数表、不做「功能罗列」式念稿 |

## 二、卖点排序（前 3 秒必须出现第 1 条）

1. **层级不塌**：文件夹还是文件夹，文档还是文档（对照：手动粘贴会把树压成一条线）
2. **真搬过**：738 个库的实拍列表，每张卡片写着来源地址和文档数
3. **规模敢亮**：一次导入 1210 个节点（目录 83 / 文件 1127），实测输出可截
4. **省事**：图片一并上传、断点续跑、失败静置重试（一句话带过，不展开）

## 三、风格三选一

| | A 深色科技 | B 浅色文档 | C 高对比杂志 |
|---|---|---|---|
| 观感 | 终端 + 网格底 + 冷光，程序员熟悉 | 贴近语雀本身的界面语言，像产品说明书 | 大字 + 橙红色块，冲击力最强，适合信息流 |
| 强项 | 命令行证据天然可信 | 与产品截图同源，不打架 | 3 秒内抓住注意力 |
| 弱项 | 深色科技风已被滥用，作者本人点过名 | 平淡，不利停滑 | 与「工具类」气质有距离，容易像广告 |
| 建议 | 备选 | **推荐**（截图多、白底更像素级还原） | 备选（若主要投 X 信息流） |

三张样帧都是用**真实素材**拼的，不是示意图：A 用真终端输出，B/C 用真语雀截图（私有库已裁掉）。
