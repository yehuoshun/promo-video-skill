## 踩到并修掉的 8 个问题

1. **`public/` 里的图必须过 `staticFile()`**。直接 `src="terminal.png"` 时 `remotion still` 抛
   `dispatchEventForPluginEventSystem` 长栈，三个截图场景全渲染失败；换成 `src={staticFile(src)}` 立刻好。
2. **旁白电平太低**。SAPI 输出峰值不低、RMS 只有 -26 dBFS，混出来「人声只比音乐高 5.3 dB」（规范要求 ≥8）。
   在 `gen_vo.py` 里加 `normalize_rms()`（RMS 归一到 -18、tanh 软限幅压峰值到 -1.5 dBFS，时长不变）。

2b. **SAPI 的音色本身不能交付**（人耳第一反应：「太难听」）。它是 2000 年代的拼接式合成，中文只有胡慧那几个音色。
   `gen_vo.py` 加了 `--engine edge`，走 edge-tts 的微软神经语音，默认 `zh-CN-XiaoxiaoNeural`；同样逐句合成→掐静音→归一化，
   6 句从 30.97s 缩到 22.71s（语速 4.9~6.0 字/秒，落在 2~7 的合规区间里），BGM 同时从 0.42 压到 0.32，
   复测人声 -18.2 dBFS / 纯音乐段 -27.6 dBFS，差 9.3 dB。`--engine sapi` 保留作断网兜底。
3. **字幕条压住截图卡片**。`Subtitles.tsx` 的 `marginBottom: 96` 让字幕占掉底部约 90px，
   而卡片是垂直居中的——终端卡 850 高，底边落在 y≈996，正好被字幕盖住。
   给 `Shot` 加了 `offsetY`（默认 -70，按卡片高度微调）并让卡片高度上限 ≈ 820。
4. **一屏放得下的截图不该上下渐隐**。滚动截图靠渐变藏断行，但终端整屏都在卡里，
   渐变把最关键的 `PS> python …` 命令盖掉了。`Shot` 加 `fade` 开关，终端关掉。
5. **截图卡片要按「文字实际高度」定尺寸**，不是按画面好看。
   终端图 2050×1283 = 1025 CSS 宽，卡片 1200 宽时正文 34px 可读；
   先试 1330 宽导致卡高 850 + 上移 -100，卡片顶部越界 16px（标题栏被切）。
6. **裁截图要按行边界，不能按比例硬切**。第一版按 `y 0.302~0.548` 裁知识库卡片，
   第二行卡片被切成半截；改成按卡片行间距（0.300~0.668）才对。
   目录树同理：从「第1章 语言基础」那一行起裁，否则片子里出现半行字。
7. **裁剪要从 2× 原图裁，不要从已裁过的小图再裁**。`yuque-toc.png` 第一版只有 983 宽，
   `check_assets` 报「宽度 < 1280，4K 下可能糊」；回到 3840 宽的原始截图重裁成 1459 宽才过关。
8. **`npm run typecheck` 也要用 `npm.cmd`**：`npm.ps1` 被 PowerShell 执行策略拦。

## 素材合规（这次的判断，写进规范）

- 只用**公开**知识库截图；私有库（付费课程、个人笔记）一张都不进片。
- 打码靠**裁**不靠涂：只保留公开区域，顶栏用户名、左栏知识库列表整片裁掉。
  涂抹漏一次就会把别人账号播出去，而裁掉的区域根本不存在。
- 数字要能对上：终端里的 1210 节点来自 `--dry` 真实输出；语雀树里的「所有目录节点（76）」
  是另一个库，两处不并置，避免造成「1210 全搬进这个库」的虚假对应。
- 「已经搬了七百多个库」写成 **七百多**，不写 738（那个数字含「邀请协作」标签页，口径不纯）。

## 仍然值得改进

- edge-tts 走微软 Edge 的朗读接口，**不是正式 API**：自用没问题，商业发布前应换成 CosyVoice2（Apache-2.0）或真人录音。
- `check_audio.py` 只吃 WAV。建议加一个 `--from-mp4`：内部调 ffmpeg 抽轨再测，
  现在得手工抽一次（且 ffmpeg 不在 PATH，要用 Remotion 自带的那个）。
- `loudnorm` 要单独一步：Remotion 只做混音不做响度标准化，
  交付前跑 `ffmpeg -i in.mp4 -c:v copy -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 -c:a aac -b:a 192k out.mp4`。
  注意加 `-ar 48000`，否则 loudnorm 会把音轨升到 96 kHz（`check_video` 里显示 0Hz，容易误判坏文件）。
- 多行旁白（`|` 分句）的字幕会按「一句话一条」，长句（7.5s）读起来偏慢，建议拆句时控制在 4~5 秒。
- `check_stills` 需要先把 stills 抓出来，建议 `verify.cmd` 里加一步「每个场景 35%/85% 各抓一帧」。
