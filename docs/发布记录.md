## 怎么加一行

1. **先记链接和时刻**：发布页上写的就是发布时刻（B站形如 `2026-11-13 17:01:55`），表里写成带时区的
   `2026-11-13T17:01:55+08:00`，换台机器、换个仓库都对得上账。
2. **规格从 `timing.json` 抄**，不从记忆抄：`duration` 秒、`width`×`height`。片子改过版就再记一行，
   注明「改版」，别覆盖旧行——旧行是当时发出去的那一版。
3. **顺手回填 `publish.json`**（同一支片子在本仓库里做的话）：对应平台加

   ```json
   "published": {
     "url": "https://www.bilibili.com/video/BVxxxxxxxxxx/",
     "at": "2026-11-17T22:25:40+08:00",
     "note": "合集「开源分享」第 2 集"
   }
   ```

   `scripts-win\check_publish.py` 会核对链接像不像该平台、时刻带不带时区（写错就 ERROR），
   `scripts-win\retro.cmd` 生成的复盘里也会多一行「发布」。
4. **数据快照只记当时看到的**，括号里写清记录时间。数字会变，账本不追着改。

## 怎么核平台数字（B站）

```powershell
Invoke-RestMethod 'https://api.bilibili.com/x/web-interface/view?bvid=BV1S9Wi6LE87' |
  Select-Object -ExpandProperty data |
  Select-Object bvid, title, pubdate, duration, dimension,
                @{n='view'; e={$_.stat.view}}, @{n='like'; e={$_.stat.like}},
                @{n='fav'; e={$_.stat.favorite}}, @{n='reply'; e={$_.stat.reply}}
```

`pubdate` 是 Unix 秒（UTC）。换本地时间：

```powershell
$tz = [TimeZoneInfo]::FindSystemTimeZoneById('China Standard Time')
[TimeZoneInfo]::ConvertTimeFromUtc(
  [DateTimeOffset]::FromUnixTimeSeconds(1794560515).UtcDateTime, $tz).ToString('yyyy-MM-dd HH:mm:ss')
```

上表那两条时刻就是这么核出来的（`1794560515` → 2026-11-13 17:01:55，`1794925540` → 2026-11-17 22:25:40）。
